# Fatty liver reel: ElevenLabs voiceover script

## Settings

- **Voice:** the same Egyptian male voice (Voice ID) as the H. pylori and IBS reels, so the series sounds consistent.
- **Model:** Eleven Multilingual v2 for Version A, or Eleven v3 for Version B.
- **Settings:** Stability 45–50%, Similarity 75%, Style 15–25%, Speed **1.05–1.1**.
- **Length:** the full approved script runs about 60–63 s at a natural pace. Speed 1.08 brings it to about 57 s. Don't push past 1.1, or it starts to sound rushed.
- **Export:** MP3 or WAV, uploaded as **`fatty-liver-reel/audio/voiceover.mp3`**.

## Version A: Multilingual v2 (paste as-is)

```

طب نعرف إزاي؟ <break time="0.3s" /> الدكتور ممكن يطلب تحاليل وظائف الكبد، أو سونار، وفحوصات تانية حسب حالتك. <break time="0.3s" /> ومهم تعرف إن تحليل وظائف الكبد الطبيعي لوحده مش كفاية علشان يستبعد وجود المشكلة. <break time="0.6s" />
```
