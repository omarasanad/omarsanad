# Celiac episode: narration script (Egyptian Arabic)

Drafted for this episode and fact-checked (see `docs/fact_check.md`). It follows the 8 scenes of the brief.
It runs about 105–110 s at a natural pace. Don't speed it up past about 1.08; the history and diagnosis parts need room.

- **Voice:** the same Egyptian male voice as the earlier reels (or the doctor's own recorded voice, which is preferred).
- **ElevenLabs settings:** Eleven Multilingual v2, Stability 45–50%, Similarity 75%, Style 15–25%, Speed 1.0–1.05.
- **Upload as** `celiac-animation/audio/voiceover.mp3`. The animation is keyed to these exact sentences and gets re-synced to the recording.
