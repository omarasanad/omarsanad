# IBS reel: ElevenLabs voiceover script

## Settings

- **Voice:** use the same Egyptian male voice as the H. pylori reel, so the channel sounds consistent.
- **Model:** Eleven Multilingual v2 for Version A (`<break>` tags), or Eleven v3 for Version B (audio tags).
- **Settings:** Stability 45–50%, Similarity 75%, Style 15–25%, Speed **1.0–1.05**.
- **Length:** about 52–54 s. The full approved script is long, so a slightly brisk but natural pace is the target; don't rush it.
- **Export:** MP3 or WAV, uploaded as `ibs-reel/audio/voiceover.mp3`.

"IBS" is written as «آي بي إس» so the voice says the letters in English instead of trying to read them as Arabic.

## Version A: Multilingual v2 (paste as-is)

```
بطنك بتوجعك كتير؟ <break time="0.3s" /> وبتحس بانتفاخ أو إن حركة الحمام مش منتظمة؟ <break time="0.3s" /> طب ممكن يكون القولون العصبي له علاقة بالموضوع! <break time="0.6s" />

القولون العصبي، أو الـ آي بي إس، اضطراب بيأثر على طريقة شغل الأمعاء، <break time="0.2s" /> وممكن يسبب وجع في البطن وانتفاخ وإمساك أو إسهال، <break time="0.2s" /> وأحيانًا الاتنين بالتبادل. <break time="0.6s" />

الأعراض ممكن تزيد مع التوتر والضغط النفسي، <break time="0.2s" /> أو مع أكلات معينة بتختلف من شخص للتاني. <break time="0.6s" />

طب نعمل إيه؟ <break time="0.3s" /> حاول تلاحظ الأكل اللي بيزود الأعراض عندك، <break time="0.2s" /> ونظّم مواعيد أكلك، <break time="0.2s" /> واشرب مياه كفاية، <break time="0.2s" /> واتحرك بانتظام. <break time="0.3s" /> ولو الأعراض مستمرة، الأفضل تراجع دكتور. <break time="0.6s" />

بس خلي بالك، <break time="0.2s" /> مش كل وجع بطن أو اضطراب في الحمام معناه قولون عصبي، <break time="0.2s" /> خصوصًا لو فيه دم في البراز أو نزول وزن من غير سبب. <break time="0.6s" />

متشخّصش نفسك بنفسك. <break time="0.3s" /> لو الأعراض بتتكرر، استشير دكتور علشان تعرف السبب والعلاج المناسب. <break time="0.4s" /> تابعنا لمعلومات طبية أكتر.
```

## Version B: Eleven v3 (audio tags; `<break>` is ignored)

```
[curious] بطنك بتوجعك كتير؟ ... وبتحس بانتفاخ أو إن حركة الحمام مش منتظمة؟ [warm] طب ممكن يكون القولون العصبي له علاقة بالموضوع!

[calm, explaining] القولون العصبي، أو الـ آي بي إس، اضطراب بيأثر على طريقة شغل الأمعاء، وممكن يسبب وجع في البطن وانتفاخ وإمساك أو إسهال، وأحيانًا الاتنين بالتبادل.

الأعراض ممكن تزيد مع التوتر والضغط النفسي، أو مع أكلات معينة بتختلف من شخص للتاني.

[encouraging] طب نعمل إيه؟ ... حاول تلاحظ الأكل اللي بيزود الأعراض عندك، ونظّم مواعيد أكلك، واشرب مياه كفاية، واتحرك بانتظام. ولو الأعراض مستمرة، الأفضل تراجع دكتور.

[serious] بس خلي بالك، مش كل وجع بطن أو اضطراب في الحمام معناه قولون عصبي، خصوصًا لو فيه دم في البراز أو نزول وزن من غير سبب.

[warm, reassuring] متشخّصش نفسك بنفسك. لو الأعراض بتتكرر، استشير دكتور علشان تعرف السبب والعلاج المناسب. [smiling] تابعنا لمعلومات طبية أكتر.
```

## Pronunciation fixes (only if a word comes out wrong)

| Word | Use instead | Sounds like |
|------|-------------|-------------|
| متشخّصش | مَتْشَخَّصْش | ma-tsha-khas-sh |
| بتوجعك | بِتْوَجَّعَك | bit-wag-ga'ak |
| نظّم | نَظَّم | naz-zam |
| الاتنين | الاِتْنين | el-et-neen |
| آي بي إس | IBS (Latin) | if the Arabic spelling sounds odd |
| مياه | مَيَّة | mayya (more colloquial, optional) |

Note: «مياه» is kept from the approved script; «مَيَّة» is the more everyday Egyptian word if you prefer it in the voice.
The on-screen subtitles keep the approved wording either way.
